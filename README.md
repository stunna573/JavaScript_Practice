# JavaScript Portfolio

A dedicated collection of JavaScript learning exercises and practical project scripts, kept separate from the HTML/CSS portfolio.

## Topics and skills represented
- JavaScript syntax and fundamentals in the learning notes
- DOM selection and manipulation
- Event listeners and form interactions
- Input checking and basic validation
- Browser storage and state handling in project code
- Reusable functions and multi-file project organization
- Practical scripts for calculator, budgeting, database-table, chatbot-style, and StayNest projects

The source included both active code and commented learning attempts. Learning notes are retained, while practical project scripts are grouped separately.

## Structure
- `learning/`: fundamentals, DOM/event practice, and exercises
- `projects/`: project-specific scripts, including calculator, budgeting, database simulator, FilesClaude, and StayNest iterations

## Running the scripts
These are browser-side JavaScript files. Most expect matching HTML elements and CSS assets from the companion **HTML-CSS Portfolio**. Open the matching HTML page in a browser (or use VS Code Live Server) after combining its companion files.

## Companion repository
See `PROJECT_COMPANIONS.md` for the matching project folders in the HTML-CSS portfolio.
