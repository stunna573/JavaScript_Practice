| `projects/StayNest/Favorites-Experiment/` | `projects/StayNest/Favorites-Experiment/` |
| `projects/StayNest/Versions/` | `projects/StayNest/Versions/` |

To run a complete website project, combine the matching HTML, CSS, assets, and JavaScript files in a local working copy. The repositories are separated for portfolio presentation, not because the browser files are independent.
